# Handoff template

Append to Beads notes at a meaningful boundary. Keep decisions in architecture and live work in the tracker.

```text
Task and status:
Owner / intended receiver:
Branch, worktree, integration base:
Commit / PR / uncommitted location:

Delivered behavior or decisions:
Architecture/strategy changes:

Validation:
- Exact command or scenario -> actual result
- Environment, fixtures, source identity, and evidence location
- Omitted checks and why

Open findings, blockers, and risks:
Next concrete action:
Review / integration required:
Task-owned process and worktree cleanup:
Last Dolt sync result, or local-only state:
```
