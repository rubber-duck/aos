# Task template

Use this body for a Beads task, with detailed acceptance also recorded in its acceptance field. Link to the owning design instead of copying it. Fill implementation locations and evidence when known.

```text
Goal:
Current problem and concrete intended result.

References:
Owning architecture/strategy documents and prerequisite Beads IDs.
Create blocking edges for real prerequisites.

Scope:
Affected boundaries, integration owner, and exclusions.
Branch/worktree and integration base when claimed.

Acceptance:
Observable outcomes, including relevant failures and lifecycle behavior.
Proposals must identify decisions awaiting user review.

Validation:
Smallest useful environment, real participants, fixtures, assertions,
maintained scenarios, failure evidence, and inputs invalidating prior results.
Documentation-only work names document checks.

Handoff:
Actual results, open decisions, and next action; use the handoff template.
```
